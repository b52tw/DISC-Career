# 🐾 動物性格地圖｜DISC 行為風格小測驗

用老虎、孔雀、無尾熊、貓頭鷹四種動物，代表 DISC 模型的四種行為傾向。32 題情境題，約 5 分鐘。

- **單一檔案**：整個網站就是 `index.html`，沒有後端、不需要建置
- **進度保存**：作答存在瀏覽器 localStorage，中途離開可繼續
- **結果報告**：主型／副型組合、雷達圖＋長條分布圖、優勢與盲點、溝通建議、職涯方向
- **深色模式**：跟隨系統，也可以手動切換
- **分享連結**：結果網址形如 `#r=D10-I5-S5-C12`，朋友打開就能看到
- **列印／存 PDF**：結果頁按一下即可

## 部署到 GitHub Pages

1. 把 `index.html` 放在倉庫根目錄
2. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save
3. 約一分鐘後，網址會是 `https://<你的帳號>.github.io/<倉庫名稱>/`

也可以直接把倉庫接到 Cloudflare Pages（Build command 留空，Output directory 填 `/`）。

## 怎麼修改

全部都在 `index.html` 的 `<script>` 裡：

| 想改什麼 | 找這個變數 |
|---|---|
| 題目與選項 | `Q`（每題一個陣列：題目＋ D/I/S/C 四個選項） |
| 四種動物的報告文字 | `TYPES` |
| 主副型組合的說明 | `PAIRS` |
| 顏色 | 檔案最上方 CSS 的 `--d` `--i` `--s` `--c` |

題目數量可以自由增減，計分與進度條會自動跟著變。改了題目後，舊的瀏覽器進度會自動失效（避免對不上）。
